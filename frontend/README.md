# Frontend

The frontend is a Vite + React application for the MMKG demo. It shows model-performance views, entity/attribute-completion views, and the 3D knowledge-graph visualization.

## Install

```bash
npm install
```

## Start

```bash
npm run dev
```

The Vite dev server runs on:

```text
http://localhost:3000
```

## Backend Dependencies

For the full UI, start both backend services:

- FastAPI: `http://127.0.0.1:8000`
- Flask KG service: `http://127.0.0.1:5000`

The project-level startup scripts start all services together:

Windows PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File ..\scripts\start-dev.ps1
```

macOS/Linux:

```bash
bash ../scripts/start-dev.sh
```

## Environment

The checked-in [.env.example](.env.example) documents frontend environment variables. Copy it to `.env` only when you need to override defaults.

Typical local defaults:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Notes

- The KG page currently calls `http://127.0.0.1:5000` directly and depends on processed KG files generated by `../kg/convert_openbg.py` and `../kg/generate_metadata.py`.
- The Attribute Completion page depends on local model artifacts under `../ml/artifacts/production_models/` or the fallback outputs directory.
- Do not commit `node_modules/`, `.env`, or generated build output.
