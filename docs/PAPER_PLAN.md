# 多模态知识图谱补全论文任务陈述与整体规划

## 1. 任务陈述

本课题面向多模态知识图谱补全任务，重点研究在文本与图像信息质量不均衡、部分实体缺失图像模态的条件下，如何提升链路预测与属性补全的鲁棒性和准确性。

当前系统已具备以下工作基础：

- 以 OpenBG-IMG 为主要实验数据集，完成了文本和图像缓存构建、训练、推理与前后端展示流程。
- 已实现基于 `ComplEx` 解码器的多模态知识图谱补全模型。
- 已实现关系感知门控融合、实体残差补偿、缺失图像占位向量、图像模态 dropout 等机制。
- 已具备 `early fusion`、`gate-only`、`residual-only`、`fusion+residual` 等配置基础，具备开展消融实验的条件。

因此，后续论文工作的核心任务不是“从零开始做模型”，而是把现有工作进一步整理为一套问题明确、方法清晰、实验充分、结论可信的论文成果。

## 2. 论文定位

### 2.1 建议的研究问题

可以将论文问题定义为：

“在多模态知识图谱补全任务中，当视觉模态存在缺失或与结构语义不完全对齐时，如何设计更稳健的融合与补偿机制，以提升实体表示质量和下游预测性能？”

### 2.2 建议的论文定位

当前工作更适合定位为：

- 面向缺失视觉模态的多模态知识图谱补全方法
- 关系感知门控与残差补偿的实体表示学习方法
- 偏应用验证型、实验驱动型的方法改进论文

不建议将其表述为：

- 完全全新的基础模型框架
- 颠覆性创新的通用 MMKG 模型

因为从学术判断上看，当前方法具有一定创新性，但创新强度属于“问题导向的结构改进”，更适合走稳健实验和针对性建模路线。

## 3. 当前模型可归纳的改进点

结合现有代码实现，当前模型的改进点可以概括为以下三项。

### 3.1 关系感知的跨模态门控融合

模型不是直接拼接文本和图像，而是使用关系相关的门控机制，对文本模态和图像模态进行动态加权，从而让不同关系下的实体表示具备不同的模态偏好。

这一点解决的问题是：

- 不同关系对图像和文本的依赖程度不同
- 统一固定融合权重难以适应多种关系类型

### 3.2 实体级残差补偿机制

在融合表示之外，为每个实体引入可学习的残差向量，用于补偿文本和图像预训练特征无法充分表达的实体私有信息。

这一点尤其适用于：

- 图像缺失实体
- 图像噪声较大实体
- 文本描述不足实体
- 仅依赖预训练模态特征难以精确区分的实体

### 3.3 面向缺模态场景的训练细化策略

当前模型已经具备一些实用但可论文化的训练细节，包括：

- 缺图实体使用 `v_missing` 作为视觉占位表示
- 图像模态 dropout，增强模型对视觉不稳定性的鲁棒性
- 支持 `gate-only`、`residual-only`、联合模型的对比实验
- 支持融合与残差的归一化混合权重
- 支持融合 warmup 策略

这些内容单独看不属于强创新，但组合起来可以构成较完整的方法框架与实验分析基础。

## 4. 当前工作存在的主要不足

如果要往期刊论文方向推进，当前工作仍存在若干会直接影响说服力的问题。

### 4.1 输入特征处理方式需要改进

当前文本和图像缓存构建流程中，原始预训练特征会先通过随机初始化的线性层投影到 256 维，然后直接保存为固定 embedding。训练阶段并不会继续优化该投影层。

这一设计的问题包括：

- 随机投影会引入额外信息损失
- 会削弱模型效果的可解释性
- 审稿时容易被质疑为何不使用可训练投影

因此，后续应优先改为：

- 缓存原始预训练特征
- 在模型内部加入可训练投影层
- 训练时与门控和残差模块一起优化

### 4.2 当前缺少系统性的实验结果支撑

目前代码层面已经具备若干对照配置，但仓库中尚未形成完整、可直接支撑论文的实验结果矩阵，例如：

- 多随机种子结果
- 主结果表
- 完整消融表
- 缺图/有图实体分组结果
- 统计显著性或方差分析

### 4.3 数据集广度偏弱

当前主要围绕 OpenBG-IMG 展开。单数据集可以支撑毕设，但对期刊论文而言说服力偏弱。

如果条件允许，建议增加至少一个公开可复现实验数据集，增强结论的普适性。

## 5. 论文目标判断

### 5.1 毕设层面

从毕设角度看，当前工作已经可以认为“有模型改进”，因为它并非简单复现，而是基于多模态补全任务做了结构调整和训练设计。

### 5.2 论文层面

从论文角度看，当前工作具备写作潜力，但尚未达到“可以直接投稿”的成熟状态。

较为理性的判断如下：

- 若后续补齐实验、修正输入特征流程、完善论文叙事，则具备投稿 4 区期刊的可能性。
- 若希望提升到较稳妥的 3 区水平，则还需要更强的 baseline、更完整的数据集验证以及更严谨的分析。

因此，本工作的现实目标建议设定为：

- 第一目标：形成一篇结构完整、实验充分的 4 区可投稿论文
- 第二目标：若实验结果明显优于预期，再评估是否进一步冲击 3 区

## 6. 论文工作整体规划

后续工作建议分为四个阶段推进。

### 第一阶段：方法与实现整改

目标是让当前模型从“能跑”变成“能讲清楚且经得起质疑”。

主要任务如下：

1. 重构特征输入流程
- 缓存文本原始特征
- 缓存图像原始特征
- 在模型内加入文本和图像可训练投影层

2. 统一模型版本
- 明确当前论文主模型的最终结构
- 明确哪些配置属于 baseline，哪些属于主方法
- 删除或冻结无关试验分支，避免后期写作混乱

3. 明确论文贡献点
- 最多保留 2 到 3 个主贡献
- 每个贡献都要能用实验验证

建议本阶段输出：

- 一个稳定的论文主模型版本
- 一份最终方法框图
- 一份核心公式说明

### 第二阶段：实验体系搭建

目标是形成完整的论文实验矩阵。

主要任务如下：

1. 构建 baseline 组
- Text-only
- Early Fusion
- Gate-only
- Residual-only
- Full Model

2. 开展消融实验
- 去掉 relation-aware bias
- 去掉 residual
- 去掉 normalized mix
- 去掉 warmup
- 调整 image dropout

3. 开展稳定性实验
- 至少 3 个随机种子
- 报告平均值和标准差

4. 开展分组实验
- 有图实体 vs 缺图实体
- 不同关系类型
- 不同 gate 区间

5. 如条件允许，增加第二数据集

建议本阶段输出：

- 主结果表
- 消融实验表
- 分组实验表
- 参数敏感性表或曲线图

### 第三阶段：分析与可视化

目标是让论文不只是“报结果”，而是能解释为什么有效。

主要任务如下：

1. 绘制模型结构图
2. 绘制门控权重分布图
3. 绘制 residual 权重变化图
4. 分析典型案例
- 成功案例
- 失败案例
- 缺图实体案例

建议本阶段输出：

- 论文配图
- 案例分析表
- 误差分析小节材料

### 第四阶段：论文写作与投稿

目标是形成完整稿件并完成投稿准备。

主要任务如下：

1. 撰写初稿
- 引言
- 相关工作
- 方法
- 实验
- 结论

2. 完善参考文献
- MMKG completion
- multimodal fusion
- missing modality learning
- knowledge graph embedding

3. 根据目标期刊模板排版
4. 进行导师审阅与修改
5. 根据目标期刊要求补充英文摘要、图表说明和投稿信

## 7. 具体执行清单

以下是建议优先级从高到低的具体任务列表。

### P0：必须优先完成

- 将随机固定投影改为模型内可训练投影
- 确定最终论文主模型结构
- 建立完整 baseline 配置
- 跑通主实验与基本消融

### P1：强烈建议完成

- 跑 3 个随机种子
- 做缺图/有图实体分组结果
- 做 gate 和 residual 可视化
- 补充方法图和公式说明

### P2：有条件时完成

- 增加第二数据集
- 增加更强外部 baseline
- 做统计显著性检验
- 增加案例分析与错误分析

## 8. 预期论文结构

建议采用如下结构：

1. 引言
- 研究背景
- 问题挑战
- 现有方法不足
- 本文贡献

2. 相关工作

3. 方法
- 任务定义
- 文本与图像表示构建
- 关系感知门控融合
- 实体残差补偿

4. 实验
- 数据集
- 评价指标
- 实验设置
- 主结果
- 消融实验
- 分组分析
- 可视化与案例分析

5. 结论与展望

## 9. 时间规划建议

如果按 6 周推进，可参考如下安排。

### 第 1 周

- 明确论文主模型
- 重构特征输入流程
- 固定训练配置和实验脚本

### 第 2 周

- 跑 baseline
- 跑 full model
- 初步整理主结果

### 第 3 周

- 跑消融实验
- 跑多 seed 实验

- 做可视化和案例分析
- 形成方法图、结果图和表格

## 10. 与导师沟通时的建议表述

可以将本工作表述为：

“目前毕设工作已经不只是复现，而是在多模态知识图谱补全任务上做了针对性的模型改进。现有方法主要围绕关系感知门控融合和实体残差补偿展开，重点解决视觉模态缺失和多模态信息不完整带来的表示不足问题。从论文角度看，目前已经具备选题和方法基础，但还需要进一步补强实验和模型实现细节，尤其是完善 baseline、消融、多随机种子结果，以及优化输入特征处理流程。若后续实验结果稳定，投稿 4 区期刊是较现实的目标，3 区则需要视结果和工作量进一步评估。” 

## 11. 最终目标

本论文工作的最终目标不是单纯“写出一篇文章”，而是完成以下三件事：

- 形成一套问题明确、结构完整的多模态知识图谱补全方法
- 形成一组能够支撑结论的系统实验结果
- 形成一篇达到期刊投稿标准的论文稿件

如果后续推进顺利，本课题完全可以从“毕设项目”进一步提升为“可投稿论文工作”。
